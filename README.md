# phyloshapetest

`phyloshapetest` is a Python library for modeling and transforming vector and face geometry 
in phylogenetic structures. It supports face-relative coordinate systems, vector transformations, 
and geometric computations in 3D.

## Features

- Convert points and vectors between global and face-relative coordinates
- Support for triangle-based `Face` objects and `Vector` objects
- Modular architecture with NumPy-based transformations
